LUXY Protocol

A bonding-curve launchpad on Robinhood Chain (4663). Deploy tokens in one signature. Let a deterministic curve discover price. Graduate into permanent public liquidity — all on-chain, all automated.

Introduction

Luxy is a fair-launch protocol. There is no presale, no team allocation, and no special-access round. Every token follows the same four-state lifecycle: Deploy → Discover → Graduate → Earn.

Design Principles

  • One-signature deploy. Token + pricing contract deployed atomically — no multi-step wizard, no private configuration.
  • On-chain quotes only. The buy/sell screen reads the same getQuote() that executes your trade. No off-chain oracle, no hidden spread.
  • Deterministic graduation. At ≈3.96 ETH reserve, the curve stops and liquidity seeds automatically. Nobody can pause it, nobody can divert it.
  • Non-custodial throughout. Funds settle directly against the curve or pool. Luxy holds nothing at any point.

Bonding Curve

The curve prices every trade from on-chain reserves. Buys push supply up and lift the quote; sells walk it back down the same path.

P(s) = P₀ + ΔP · s²
P(s) — price quote at supply s (in ETH)
P₀ — starting price floor
ΔP — steepness coefficient (fixed per token)
s — tokens sold so far (cumulative)

Why Quadratic?

The s² term makes the curve convex: early buyers get the best price, and the quote rises faster as supply approaches target. Late entrants pay more — front-running buys you a worse price, not a better one.

Quote Execution

Every quote on the Swap page and token trade panel reads getQuote(uint256 amount, bool isBuy). The number shown is the exact calculation your transaction will execute — not an off-chain estimate overlaying the real price. No hidden spread, no oracle latency.

solidity function getQuote(
  uint256 amount,
  bool isBuy
) external view returns (uint256 quote) {
  uint256 s = totalSold;
  uint256 base = P0 + deltaP * s * s / 1e18;
  if (isBuy) {
    quote = amount * base / 1e18;
  } else {
    quote = amount * base / 1e18;
  }
}

Launchpad

Deploying a token requires: a name, a ticker, and an optional description. One transaction. No code. No reserved allocation.

Deploy Flow

  • Creator fills in name + ticker + optional metadata (image, X, Telegram, website).
  • A single transaction deploys the token (ERC20) and its bonded curve pricing contract atomically.
  • The token appears on the Launchpad immediately — visible but not tradeable until the first buy hits the curve.
  • State moves: Deploying → Discovering (on first buy).

Metadata

Name, ticker, image, and social links are stored off-chain via the Luxy metadata registry. The launchpad page displays them; the contract enforces only the financial parameters — price function, limits, and graduation mechanics.

Graduation

At ≈3.96 ETH reserve, the token graduates. This is automatic — nobody triggers it, nobody can stop it, nobody can divert the funds.

What Happens

  • Curve stops quoting — getQuote() reverts for new trades.
  • Remaining token supply + all collected ETH are paired at the migration ratio.
  • Paired tokens and ETH are deposited as opening liquidity in a Uniswap V3 pool.
  • The LP position is permanently locked — tokens are never returned to the creator or burned.
  • State: Discovering → Graduated.
What about unsold tokens? Nothing sits idle. All remaining supply + ETH goes straight into the pool. The creator does not get tokens back.

Trading

Trades are sized in exact-token or exact-ETH terms. Every signature includes a minAmountOut — if the fill isn't at least that good, the entire transaction reverts.

Slippage

  • Presets: 0.5% · 1% · 3%
  • Custom slippage supported
  • minAmountOut is checked on-chain — the UI cannot override it
solidity function swap(
  address token,
  uint256 amountIn,
  uint256 minAmountOut
) external returns (uint256 amountOut) {
  amountOut = _executeSwap(token, amountIn);
  require(amountOut >= minAmountOut, "LUXY: slippage");
}

Post-Graduation

Trading moves to the AMM. Slippage works the same way — minAmountOut still guards against sandwiching. The curve is retired.

Referrals

Any wallet can register a referral code and earn a share of protocol fees from referred trades. Fully on-chain.

  • One code per address. Permanent once set.
  • Tiered share. Earnings scale with referred volume.
  • Withdraw anytime. No lock period, no minimum.
  • Queryable events. All referrals and payouts emit indexed events for off-chain indexing.

Security

Luxy is non-custodial at execution, not governance-free. The line between code guarantees and administrative controls is documented here so it's visible before anyone signs.

Enforced On-Chain

  • Trade pricing. Priced by the curve contract, settled atomically. No off-chain matching layer.
  • Slippage floor. Your signed minAmountOut is checked on-chain. A worse fill reverts.
  • Wallet cap. 5% limit checked on every transfer at the token contract level. Curve and pool exempt.
  • Pool lock. The destination AMM pool exists before the token is public and stays locked until graduation completes.

Governance Scope

  • Launch access. Can be paused or approval-gated.
  • Address blocking. Specific addresses can be restricted from trading — a platform tool, not creator control.
  • Fee parameters. Governance sets buy/sell fees for new launches, within hard-coded limits.
What governance CANNOT do: change a live token's curve, unlock a graduated pool, mint tokens, or access user funds. These are contract invariants, not configurable parameters.

FAQ

Why didn't my quote exactly match my fill?

The quote reflects curve state at the moment you requested it. Any trade landing before yours moves the price — that's what your slippage tolerance bounds. Set it higher in volatile periods.

Why can't I buy more?

You've likely hit the per-transaction cap (5% of target) or max-wallet limit (5% of supply). Split buys across multiple transactions, spaced so the curve can move between them.

What happens to unsold tokens at graduation?

Pair with collected ETH → deposited as opening liquidity. Nothing is returned or burned. The creator gets zero special treatment.

Does staking pay a fixed rate?

No. The displayed APR is a snapshot — it moves with emissions rate, LP composition, and participation. Treat it as a directional estimate, not a yield guarantee.

Which chain?

Robinhood Chain exclusively. Chain ID 4663. Add the RPC from the app navbar.
